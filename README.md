# DevCircle — AI-Powered Developer Career Platform

DevCircle is a full-stack AI-powered platform designed to help developers prepare for technical interviews, improve resumes, and streamline placement preparation workflows.

Built using Next.js, TypeScript, MongoDB, and OpenRouter APIs with focus on scalable backend architecture, responsive UI, and AI-integrated developer tools.

---

## 🚀 Features

* 🤖 AI-powered mock interview system
* 📄 ATS resume scoring and analysis
* 💡 AI-based career assistance workflows
* 🔐 JWT authentication & protected routes
* ⚡ Scalable REST API architecture
* 📱 Fully responsive modern UI
* 🧠 Dynamic AI-generated interview feedback
* 💾 Persistent user data management
